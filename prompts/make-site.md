# Промпт: сделать сайт-полёт по резюме и GitHub на движке SpaceShip

Скопируйте текст ниже в Claude Code, Codex или другой ИИ-агент, который открыл этот репозиторий.
Агент сам соберёт сайт: транспорт прилетит, пользователь полетит к проектам, у каждого проекта откроется карточка.

---

Ты собираешь личный сайт-портфолио на движке SpaceShip (этот репозиторий). Сайт — это полёт: транспорт прилетает, человек управляет им и летит к проектам. Проект — это планета, остров или ворота на трассе; в него можно пристыковаться и прочитать карточку.

## Что нужно от меня

- Резюме: текст или PDF. Если его нет, спроси один раз и жди.
- Логин GitHub. По умолчанию — из content/site.json (поле site.github).
- Пожелания, если есть: какой транспорт, какие цвета, какие проекты показать. Если не сказано — выбирай сам по правилам ниже.

## Шаги

1. Обнови снимок GitHub: `npm run fetch`. Он сохранит только публичные репозитории без форков. Приватные репозитории не попадают на сайт и не упоминаются ни в каком тексте.

2. Заполни content/site.json по схеме из prompts/site-schema.md.
   - person — только факты из резюме. Не выдумывай цифры, компании, даты, навыки, награды.
   - contacts — только то, что есть в резюме. Телефон на сайт не выводи, если тебя не попросили.
   - Тексты пиши по-русски, коротко, без восклицаний и превосходных степеней.

3. Выбери транспорт (поле site.vehicle) по профилю человека:

   | Профиль | site.vehicle | Мир, в котором он летает |
   |---|---|---|
   | продукт, ИИ, аналитика, управление, консалтинг | plane | небо над морем |
   | разработка, игры, 3D, космос | spaceship | космос |
   | сервис, логистика, выездные работы, автодилер | car | неоновая трасса |
   | курьерская работа, быстрые поездки, спорт | motorcycle | неоновая трасса |
   | спасение, медицина, работа с выездами | helicopter | небо над морем |

   Если профиль не укладывается в таблицу, поставь `"vehicle": "auto"` и при необходимости добавь свои правила в site.vehicleRules. Движок выберет транспорт сам по тексту профиля.

4. Выбери 4–7 лучших проектов (projects.items).
   - Приоритет: есть живой сайт, есть звёзды, работа похожа на целевую роль.
   - Для каждого проекта: `repo` — точное имя из content/github.json; `name` — читаемое название; `short` — одно-два предложения, до 140 символов, факты из README или резюме; `when` — год; `role` — твоя роль в проекте; `tags` — 2–4 слова.
   - Если в README нет фактов, пиши только то, что видно из названия и описания репозитория.

5. Цвета: поле site.accent, 3–4 hex-цвета. Первый цвет — главный (подсветка кнопок, кромки, сияние). Подбирай по характеру человека и профессии: спокойный и технический — холодные синие и бирюзовые; творческий — тёплые розовые и золотые.

6. Проверь:
   - `npm run build` — проверит контент. Если сборка падает, исправь текст ошибки, а не обходи проверку.
   - `npm run dev`, затем открой http://127.0.0.1:8000/index.html?debug=1.
   - Проверь каждый транспорт: `?vehicle=plane`, `?vehicle=spaceship`, `?vehicle=helicopter`, `?vehicle=car`, `?vehicle=motorcycle`. Сайт должен собираться без ошибок во всех пяти.

7. Не меняй файлы движка (src/, index.html) без явной просьбы. Новый вид транспорта или новый мир описаны в prompts/extend-engine.md и делаются отдельно.

## Что вернуть в ответе

- Какой транспорт выбран и почему; какой мир.
- Список проектов с короткими описаниями.
- Что я должен проверить глазами: тексты, цвета, порядок проектов.
- Что ты НЕ смог проверить (например, живые ссылки или отрисовку на видеокарте).

## Варианты дизайна без правки движка

Если нужен другой характер сайта, меняй только конфиг:
- Другой транспорт — поле site.vehicle (или `?vehicle=` в адресе, для просмотра).
- Другие цвета — site.accent.
- Другая подача — порядок и тексты проектов, интро (site.intro).
- Другой мир для того же транспорта — поле site.environment (`space`, `sky`, `road`), если совместимо с транспортом.

Если нужен новый визуальный язык (другой мир или другой вид транспорта), это уже задача для prompts/extend-engine.md.
