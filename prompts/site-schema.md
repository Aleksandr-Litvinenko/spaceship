# Схема content/site.json

Файл читает движок в браузере и сборка в Node. Ошибки в нём ловятся при `npm run build`.

## Полная структура

```json
{
  "site": {
    "title": "Имя Фамилия",
    "lang": "ru",
    "github": "логин-на-github",
    "domain": "spaceship.product1c.ru",
    "vehicle": "auto",
    "environment": "auto",
    "accent": ["#ff5fd2", "#2de1c2", "#ffcf6b", "#7b5cff"],
    "intro": {
      "eyebrow": "Резюме · позывной ALX-01",
      "tagline": ""
    },
    "vehicleRules": [
      { "match": "регулярное выражение, без учёта регистра", "vehicle": "car" }
    ]
  },
  "person": {
    "name": "", "callsign": "", "role": "", "lead": "", "bio": "", "seeking": "",
    "stats": [{ "value": "", "label": "" }],
    "experience": [{ "period": "", "role": "", "org": "" }],
    "skills": [{ "group": "", "items": [""] }],
    "education": [""],
    "certificates": [""],
    "languages": "",
    "principles": [""]
  },
  "contacts": [{ "label": "", "value": "", "url": "" }],
  "projects": {
    "mode": "curated",
    "top": 6,
    "items": [
      {
        "repo": "имя-репозитория-из-github.json",
        "name": "Название на сайте",
        "when": "2026",
        "role": "Твоя роль",
        "short": "Одно-два предложения.",
        "tags": ["тег", "тег"],
        "live": "https://пример.ru",
        "body": "",
        "bullets": [""],
        "metrics": [{ "value": "+30%", "label": "что измерили" }]
      }
    ]
  }
}
```

## Поля

- **site.vehicle** — `plane`, `spaceship`, `helicopter`, `car`, `motorcycle` или `auto`. При `auto` движок смотрит на текст профиля и правила из `vehicleRules`; если ничего не совпало, берёт `plane`.
- **site.environment** — `auto` (мир следует за транспортом), либо `space`, `sky`, `road`. Указывать вручную имеет смысл, только если понимаешь, что делаешь: мир и транспорт должны подходить друг другу.
- **site.intro.tagline** — если пусто, движок подставит фразу сам: «Я — корабль. Проекты — планеты.» и т.п.
- **site.vehicleRules** — список правил для `auto`. Первое совпадение побеждает. Свои правила идут раньше встроенных.
- **projects.mode** — `curated` (берём `items` как есть) или `top` (движок сам выбирает N лучших по звёздам, живому сайту и свежести; `items` тогда не нужен).
- **projects.items[].repo** — имя репозитория. Если его нет в content/github.json, сборка предупредит, а карточка будет без ссылки и звёзд.
- **projects.items[].live** — живой адрес; если пусто, берётся homepage из GitHub.
- **accent** — от одного до четырёх hex-цветов. Первый — основной.

## Какой транспорт в каком мире

| vehicle | environment | Что делает проект |
|---|---|---|
| spaceship | space | планета: в неё стыкуются, у каждой своё кольцо и атмосфера |
| plane | sky | остров над морем: голубой маяк и неоновое кольцо |
| helicopter | sky | то же, что plane, но умеет зависать и подниматься (Q и E) |
| car | road | арка-ворота поперёк неоновой трассы, на табличке название |
| motorcycle | road | те же ворота; мотоцикл ложится в поворот |

## Правила для текстов

- Все тексты про проекты — из README и резюме. Ничего не придумывай.
- `short` — до 140 символов. Если дольше, сократи, не теряя фактов.
- Цифры (`metrics`) — только из резюме или README с указанием, откуда они.
- Одна мысль в предложении. Без слов «уникальный», «революционный», «лучший».
