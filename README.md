# SpaceShip — движок портфолио-полётов

Личный сайт, в котором транспорт прилетает и летит к вашим проектам. Самолёт, корабль, вертолёт, машина или мотоцикл сами подбираются под профиль или выбираются вручную. Каждый проект — отдельный мир: планета, остров или ворота на трассе. Пристыковались — открылась карточка с описанием и ссылками на GitHub и живой сайт.

Контент берётся из двух мест:
- `content/site.json` — ваши тексты, проекты и цвета;
- `content/github.json` — снимок публичных репозиториев GitHub (`npm run fetch`).

Движок ничего не знает о конкретном человеке: всё, что видно на сайте, приходит из этих двух файлов.

## Быстрый старт

Нужны Node.js 18+ и Python 3 (для локального сервера). WebGL в браузере обязателен.

```bash
npm run fetch      # снимок публичных репозиториев из content/site.json → content/github.json
npm run dev        # локальный сервер на http://127.0.0.1:8000
```

Откройте http://127.0.0.1:8000/index.html и нажмите «Взлететь» после прилёта.

Параметр `?debug=1` открывает состояние полёта в `window.spaceship` для отладки в консоли.

## Транспорт и мир

| Транспорт | Мир | Что делает |
|---|---|---|
| `spaceship` | космос | летит между планетами |
| `plane` | небо над морем | летит между островами |
| `helicopter` | небо над морем | зависает и поднимается (Q и E) |
| `car` | неоновая трасса | едет через ворота вдоль дороги |
| `motorcycle` | неоновая трасса | едет и ложится в поворот |

Выбор задаётся полем `site.vehicle` в `content/site.json`:
- конкретный транспорт — например, `"plane"`;
- `"auto"` — движок смотрит на текст профиля и подбирает транспорт по правилам из `src/core/content.js` и `site.vehicleRules`.

Посмотреть другой транспорт, не меняя конфиг: `index.html?vehicle=car`.

## Управление

- `W A S D` или стрелки — курс и тангаж;
- `Shift` — форсаж, `Space` — тормоз;
- `Q` / `E` — вверх и вниз (вертолёт);
- курсор — рулит, если двигаться от центра экрана;
- клик по цели или строке маршрута — автопилот к проекту;
- `Enter` — стыковка с целью, на которую вы вышли на орбиту;
- `Esc` — вернуться в ручной полёт или закрыть карточку;
- `M` — звук двигателя (по умолчанию выключен).

## Структура

```
index.html            страница-оболочка
content/
  site.json           ваши тексты, проекты, цвета, транспорт (правите вы)
  github.json         снимок GitHub (создаёт npm run fetch)
src/
  main.js             точка входа: контент → мир → транспорт → цикл
  three.js            единая точка входа для three.js (CDN, без importmap)
  core/
    content.js        сборка контента и выбор транспорта
    controller.js     управление: полёт, езда, автопилот, стыковка, камера
    ui.js             интерфейс: миссии, подписи, карточки, телеметрия
    gfx.js            процедурные текстуры и шейдеры
    effects.js        частицы выхлопа
    input.js          клавиатура, курсор, клик
  env/                миры: space.js, sky.js, road.js (+ common.js, index.js)
  vehicles/           модели транспорта + реестр index.js
prompts/              промпты для ИИ-агентов: сделать сайт, описать схему, добавить транспорт
deploy/               конфиг nginx для выкладки
scripts/              fetch-github.mjs, build.mjs, deploy-jino.sh
```

## Сборка и выкладка

```bash
npm run build        # проверит контент и соберёт dist/
npm run deploy       # соберёт dist/ и выложит на spaceship.product1c.ru (Jino VPS)
```

`npm run build` останавливается, если контент битый: нет проектов, неизвестный транспорт или мир. Текст ошибки подскажет, что поправить.

`npm run deploy` заливает сайт по SSH. Адрес сервера, порт и ключ задаются переменными окружения, в репозиторий они не попадают:

```bash
JINO_HOST=<IP сервера> JINO_PORT=<порт SSH> JINO_KEY=<путь к приватному ключу> npm run deploy
```

Если ключ хоста сохранён под алиасом (как в `known_hosts`), добавьте `JINO_HOSTKEY_ALIAS=<алиас>`. При первой выкладке устанавливается конфиг nginx из `deploy/nginx-spaceship.conf`. Редирект HTTP→HTTPS в нём намеренно не стоит: TLS завершает прокси хостинга.

## Ограничения

- Нужен интернет: three.js грузится с jsDelivr, шрифты — с Google Fonts.
- Сцена рисуется на видеокарте. На слабых устройствах частота кадров будет ниже; разрешение ограничено 1.5x.
- Звук включается кнопкой: браузеры не разрешают звук без действия пользователя.
- Для проверки отрисовки нужен браузер с WebGL; автоматические тесты не настроены.
